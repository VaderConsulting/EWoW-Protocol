# EWoW Protocol

Realtag EWoW-C protocol tester (`EWoWProtocol.exe`) used to exercise the EWoW-C messaging protocol from a VB6 WinForms host.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `EWOW_C_Protocol_Tester` (`EWoWProtocol.vbp`) | VB6 | WinForms exe | EWoW C Protocol Tester |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `EWoWProtocol.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `MSCOMM32.OCX`
  - `TABCTL32.OCX`
